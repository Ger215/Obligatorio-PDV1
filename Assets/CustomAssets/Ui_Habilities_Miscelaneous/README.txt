Indie Game Feel – Status & UI Effects Pack
========================================

A pixel-art UI asset pack focused on clear, readable status feedback for 2D games.
Designed to improve game feel, clarity, and player awareness in action, roguelike,
RPG, and arcade-style games.

--------------------------------------------------
INCLUDED ASSETS
--------------------------------------------------

STATUS ICON SETS
• Health, shield, energy, fire, poison, lightning, and debuff icons
• Solid, readable pixel-art symbols
• Multiple visual variations for different gameplay states

COOLDOWN & STATUS RINGS
• Circular cooldown and status rings in multiple styles
• Clean ring-only versions for flexible UI composition
• Ring sets with centered status icons for instant readability

Included files:
• cooldown_rings_set_01.png

UI STATE ELEMENTS
• Ready-to-use UI symbols for buffs, debuffs, alerts, and player states
• Consistent color language across all assets
• Designed for direct in-game use or HUD overlays
